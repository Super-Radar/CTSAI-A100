进入 Python 示例目录：

```bash
cd Python雷达可视化工具示例
```

运行示例脚本：

```bash
python radarViewer.py
```

脚本启动后会打开文件选择窗口。可以选择仓库附带的示例数据：

```text
负30度_Tatget_2026_03_10_15_34_39_CTLRR-300-V2_1_RawTarget.csv
```

### 示例数据字段

RawTarget CSV 与解析器实际使用的字段名如下（与仓库示例和 RadarTools 输出大小写保持一致）：

**目标数据列（表头行）**

| 字段 | 说明 |
| --- | --- |
| ObjId | 目标编号 |
| range | 目标距离 |
| speed | 相对速度 |
| angle | 水平角 |
| snr | 信噪比 |
| X | 笛卡尔坐标 X |
| Y | 笛卡尔坐标 Y |
| RCS | 雷达散射截面积 |
| heigh | 目标高度相关字段 |
| Kstate | 跟踪状态相关字段 |
| trkReiablility | 跟踪可靠度 |

**帧级标记元数据（非目标列）**

CSV 在目标表头之后还会插入帧分隔行，例如：

```text
START,FrameNb:0,CameraNb:0,HeSaiNb:0,ARS410Nb:0
```

以及带时间戳的帧头行。解析时需区分“目标数据列”与“帧级标记”，不要把 `FrameNb`、时间戳行当作目标记录。

实际字段以仓库中的示例 CSV 为准；不同版本字段可能略有差异。

### 可视化功能

Python 示例工具提供以下参考能力：

* 读取雷达 CSV 数据
* 对目标点进行基础筛选
* 绘制点云分布
* 显示目标聚类结果
* 绘制目标轨迹
* 按帧回放目标变化
* 辅助分析目标距离、速度和角度变化

该示例适合用于快速理解雷达输出数据结构，并作为后续算法开发的起点。
