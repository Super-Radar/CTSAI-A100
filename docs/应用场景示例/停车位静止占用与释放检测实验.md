# 停车位静止占用与释放检测实验

## 1. 场景背景

停车管理、地锁控制和车位引导等应用都需要判断某个车位当前是否被占用。摄像头方案在夜间、逆光和隐私场景下存在限制，超声波或地磁方案通常只能覆盖单个车位，而毫米波雷达可以在不采集图像的情况下同时观察多个车位的占用状态变化。

静止占用检测与运动目标检测的关注点不同：车辆停稳后多普勒速度接近零，目标在点云或目标级数据中表现为位置基本不变的持续回波，检测难点从"发现运动"转为"区分静止车辆、地面多径、相邻车位车辆与真实空位"。

本示例以 CTSAI-A100 为实验设备，设计一个可重复的停车位静止占用与释放观测实验，重点记录车辆停放、保持和离开过程中目标位置与回波随时间的变化。本示例仅提供实验流程和研究方法，不构成产品性能测试，也不代表实际停车管理系统的检测指标。

## 2. 场景布置

选择一段夜间车流较少的地面停车场或封闭实验场地，将 CTSAI-A100 固定在能够同时观察到 1 至 2 个目标车位的位置，安装高度和朝向参考设备文档确定，并在实验记录中注明。

建议的场景示意如下：

```text
     车位 A（目标车位）      车位 B（相邻车位，干扰参考）
        +--------+              +--------+
        | 车辆/空 |              | 车/空  |
        +--------+              +--------+
 ------------------ 地面 ------------------
                 |
           CTSAI-A100
```

实验前应记录车位标线位置、雷达视场覆盖范围、地面材质以及附近可能产生强反射的设施（立柱、金属护栏、卷帘门）。每次改变安装位置后应重新采集空场基线数据。

## 3. 数据类型

本实验主要使用以下数据：

- 点云或目标级数据：用于观察占用目标的距离、方位、目标编号和回波强度随时间的变化。
- ADC 数据（可选）：用于研究静止车辆微弱起伏（例如发动机怠速、人员开关车门引起的微小多普勒）的原始信号特征。
- 实验元数据：包括车位状态真值记录（人工按时间戳记录车辆停入、停稳、离开的时刻）、采集时间、天气与照明条件、异常事件。

使用 RadarTools 导出 CSV 数据后，可以重点观察目标位置、目标编号与回波相关字段。具体字段名称和含义应以当前软件实际导出的 CSV 文件及仓库文档为准，不应凭空假设不存在的字段。

## 4. 研究问题

本场景可以用于研究以下问题：

1. 车辆从行驶、停稳到人员离开的全过程中，目标编号是否保持稳定，是否出现编号切换或目标分裂。
2. 车辆完全静止后，雷达能否持续输出该目标，输出间隔和回波强度是否稳定。
3. 空车位、静止车辆、相邻车位被占用三种状态的数据特征是否可以区分。
4. 目标从车位消失后，需要经过多长的判定延迟才能可靠地宣布"释放"，避免把短暂遮挡或漏检误判为离场。
5. 相邻车位车辆的边缘回波是否会落入目标车位区域，造成误占用。
6. 雨天、夜间与白天条件下同一实验流程的结果是否一致。

## 6. 实验过程

### 6.1 空车位基线

1. 确认目标车位与相邻车位均无车辆。
2. 采集至少 10 分钟空场数据，记录环境背景。
3. 观察空场中是否出现由立柱、地面或远处建筑引起的稳定虚警，并在记录中标注其位置。

### 6.2 车辆停入与停稳

1. 车辆以低速驶入目标车位并停稳，发动机熄火，人员离开。
2. 从车辆进入雷达视场前开始采集，持续到人员离开后至少 5 分钟。
3. 按时间戳记录：进入视场时刻、完全停稳时刻、熄火时刻、人员离开时刻。
4. 重复至少 3 次，可包含倒车入位和车头入位两种方式。

### 6.3 静止保持

1. 车辆保持静止占用状态，连续采集 30 分钟以上。
2. 记录目标是否持续存在、是否存在周期性丢失，以及丢失的持续时长。

### 6.4 车辆释放

1. 人员返回、启动车辆并驶离车位。
2. 记录从人员出现在视场到车辆完全离开的全过程。
3. 重复若干次，观察"从目标消失到可以判定车位释放"所需的最小等待时间。

### 6.5 相邻车位干扰

1. 目标车位保持空置，相邻车位 B 先后经历空、停车、释放三种状态。
2. 检查车位 B 的车辆回波是否在位置上侵入车位 A 的判定区域。
3. 若发生侵入，记录其在时间上与车位 B 状态变化的对应关系。

## 7. 数据分析方法

完成数据采集后，可以通过 RadarTools 或 Python 示例程序进行可视化和统计分析。

建议分析以下指标：

- 占保持时率：静止保持期间，目标车位区域存在有效目标的时间占比。
- 释放延迟：从车辆实际离开到算法宣布释放所需的等待时间分布（中位数、最大值）。
- 编号切换次数：单次停车过程中目标编号发生变化的次数。
- 空场虚警率：空车位基线中被误判为占用的帧占比。
- 邻位串扰率：车位 B 被占用而车位 A 被误判为占用的帧占比。

判定"占用"与"释放"的规则应在分析前明确定义（例如连续 N 帧存在目标判占用、连续 M 帧无目标判释放），并把 N、M 作为参数扫描，而不是只报告单组参数的结果。由于本实验使用人工时间戳作为参考，只能评价与人工记录的一致性；在没有独立验证手段时，不应将结果表述为绝对检测准确率。

## 8. 文件与实验记录建议

建议按照"日期、状态、重复编号"的方式保存数据，例如：

```text
20260929_empty_baseline_01.csv
20260929_park_in_01.csv
20260929_steady_hold_01.csv
20260929_leave_01.csv
20260929_neighbor_b_park_01.csv
```

每组实验至少记录以下信息：

| 项目 | 记录内容 |
| --- | --- |
| 实验日期 | 实际采集日期 |
| 场地 | 停车位编号与环境描述 |
| 车位状态 | 空位 / 停入 / 静止 / 释放 / 邻位占用 |
| 重复编号 | 第几次重复实验 |
| 雷达位置 | 安装位置、高度与朝向 |
| 人工真值 | 关键事件的时间戳 |
| 数据文件 | 对应的 CSV 或 ADC 文件名 |
| 异常情况 | 人员穿行、其他车辆经过、天气变化等 |

## 9. 注意事项

- 实验场地应征得管理者同意，不得影响正常停车秩序和消防通道。
- 雷达与线缆应固定并采取防护，避免被车辆碾压。
- 车辆驶入驶出时注意安全，实验人员不得停留在车辆行驶路径上。
- 地面多径、雨滴反射和远处金属设施都可能造成静止虚警，分析时应结合空场基线区分。
- 目标短暂消失不能直接解释为车辆离开，应通过释放延迟参数抑制误判。
- 数据中可能包含车牌、车架号以外无个人信息，但录像辅助记录（若使用）不应公开可识别的人脸或行人特征。
- 在完成实测前，本示例中的输出均为"预期观察内容"，不应表述为已验证的检测指标。

## 10. 预期输出

完成实验后，预期可以形成以下材料：

- 空车位、停入、静止保持、释放、邻位干扰五类状态的原始数据文件。
- 占保持时率与释放延迟的统计表。
- 不同 N/M 判定参数下的占用状态时间线图。
- 目标编号切换与短暂丢失事件清单。
- 对地面多径和邻位串扰的初步分析。

这些材料可用于学习静止目标占用检测的数据特征，也可以作为后续车位引导、地锁联动和停车场计数实验的基础。
