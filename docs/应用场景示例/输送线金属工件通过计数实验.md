# 输送线金属工件通过计数实验

## 1. 场景背景

在加工与装配车间，输送线上金属工件的通过计数常用于产量统计、节拍分析和缺料告警。光电开关方案容易被粉尘、油污和振动干扰，视觉方案需要照明且镜头易受金属反光影响。毫米波雷达对粉尘和光照不敏感，金属工件又是强反射体，适合作为输送线计数的一种实验性技术路线。

输送线计数与人员检测的关注点不同：工件尺寸小、速度快、间隔可能很短，检测难点集中在"每个工件恰好计一次"——既要避免相邻工件被合并成一个目标，也要避免同一个工件在通过过程中被拆分或重复计数。

本示例以 CTSAI-A100 为实验设备，设计一个可重复的输送线金属工件通过计数实验。本示例仅提供实验流程和研究方法，不代表产品级计数精度，也不构成工业部署方案。

## 2. 场景布置

选择一段可以安全观测的直线输送段，将 CTSAI-A100 固定在输送线侧上方，使雷达视场垂直穿过工件通过路径，避开输送带金属侧壁与辊筒的强反射区。

建议的场景示意如下：

```text
        输送方向 ─────────────▶

   ┌────┤ 工件 ●   ●   ● ├───┐
   │    输送带（侧视）       │
   └──────────┬───────────┘
              │ 安装支架
        CTSAI-A100（侧上方俯视通过路径）
```

实验前记录输送带宽度、带速、工件尺寸与材质、工件典型间距、安装高度与俯角，并采集空带基线数据。雷达与输送带的相对位置每次调整后都应重新采集基线。

## 3. 数据类型

本实验主要使用以下数据：

- 点云或目标级数据：用于观察工件通过时目标的距离、速度、目标编号和回波强度序列。
- ADC 数据（可选）：用于研究小尺寸金属工件的回波起伏特征，以及相邻工件在距离-多普勒图上能否分离。
- 实验元数据：包括人工清点数量（真值）、带速设置、工件间距、实验时长与异常事件。

使用 RadarTools 导出 CSV 数据后，可以重点观察目标位置、径向速度、目标编号等字段。具体字段名称和含义应以当前软件实际导出的 CSV 文件及仓库文档为准，不应凭空假设不存在的字段。

## 4. 研究问题

本场景可以用于研究以下问题：

1. 单个工件通过视场期间，目标编号是否稳定，是否存在一个工件被拆分为多个编号的情况。
2. 相邻工件间距缩短到什么程度时，两个工件会被合并为一个目标。
3. 工件通过速度（带速）变化是否影响每次通过事件被记录的帧数与计数稳定性。
4. 空带运行时的底噪与带体微动是否会产生虚警计数。
5. 不同尺寸或材质的工件（如铝件与钢件）在回波强度上的差异是否影响检测稳定性。
6. 基于目标编号穿越判定线的事件计数法，其漏计与重复计数的比例如何随判定参数变化。

## 6. 实验过程

### 6.1 空带基线

1. 启动输送线空载运行，不放置任何工件。
2. 采集至少 10 分钟数据，观察空带状态下是否存在稳定虚警目标。
3. 记录带速设置，以及辊筒、托辊等结构可能带来的固定反射位置。

### 6.2 单件通过

1. 在输送线上放置单个工件，让其通过雷达视场。
2. 记录该次通过在数据中出现的起止时间、目标编号序列与径向速度符号。
3. 重复至少 10 次，统计每次通过是否恰好形成一个连续事件。

### 6.3 等间距多件

1. 以固定间距（例如 1 米、0.5 米、0.3 米）依次放置多个工件。
2. 每种间距运行一批，人工清点实际通过数量。
3. 对比雷达事件计数与人工计数，记录漏计与重复计数的发生条件。

### 6.4 变速与变尺寸

1. 在设备允许范围内调整带速，重复单件与多件实验。
2. 更换不同尺寸或材质的工件，观察检测稳定性差异。

### 6.5 连续运行

1. 连续运行 30 分钟以上，期间正常上料。
2. 统计总计数与人工抽检计数的偏差，记录长时间运行中的异常事件。

## 7. 数据分析方法

完成数据采集后，可以通过 RadarTools 或 Python 示例程序进行可视化与统计分析。

建议分析以下指标：

- 事件完整率：单件通过实验中，"一个工件恰好形成一个连续事件"的比例。
- 计数偏差：雷达事件计数减去人工计数，按间距与带速分组统计。
- 漏计率与重复率：漏计事件数 / 真实通过数、重复计数事件数 / 真实通过数。
- 合并间距阈值：相邻工件开始被合并为单目标的最小间距估计。
- 虚警计数率：空带基线中单位时间的虚假事件数。

事件计数的判定规则（例如"目标编号穿越某距离判定线计一次，并在离开视场后重置"）应在分析前明确定义，并将判定线位置、去抖帧数作为可扫描参数。人工计数作为参考真值时，应说明其自身的可能误差（如漏看、时间对齐偏差），在没有更高等级验证手段时，不应将结果表述为绝对计数准确率。

## 8. 文件与实验记录建议

建议按照"日期、条件、重复编号"的方式保存数据，例如：

```text
20260929_empty_belt_01.csv
20260929_single_item_01.csv
20260929_gap1000mm_01.csv
20260929_gap300mm_02.csv
20260929_speed_change_01.csv
20260929_long_run_01.csv
```

每组实验至少记录以下信息：

| 项目 | 记录内容 |
| --- | --- |
| 实验日期 | 实际采集日期 |
| 带速 | 输送线速度设置 |
| 工件描述 | 材质、尺寸、重量 |
| 工件间距 | 多件实验的设置间距 |
| 人工真值 | 实际通过数量 |
| 雷达位置 | 安装位置、高度与俯角 |
| 数据文件 | 对应的 CSV 或 ADC 文件名 |
| 异常情况 | 卡料、人工干预、其他设备干扰等 |

## 9. 注意事项

- 实验应在输送线停机或低速状态下布置雷达，运转中严禁将手或工具伸入输送线。
- 安装支架应可靠固定，防止振动导致雷达位置漂移从而改变判定线标定。
- 金属输送带侧壁、辊筒和料斗可能产生强反射，应通过空带基线识别并在判定区域中排除。
- 小工件回波弱且起伏大，不应因为个别漏检而直接判定方案不可行，应结合间距、带速和工件尺寸分组分析。
- 车间其他设备（变频器、电机、金属切割设备）可能带来环境反射变化，异常数据应结合现场记录解释。
- 在完成实测前，本示例中的输出均为"预期观察内容"，不应表述为已验证的计数精度。
- 公开数据前应检查是否包含与具体产线、订单相关的敏感信息。

## 10. 预期输出

完成实验后，预期可以形成以下材料：

- 空带、单件、等间距多件、变速、连续运行五类状态的原始数据文件。
- 事件计数与人工计数的对照表（按间距、带速分组）。
- 漏计与重复计数事件的明细及发生条件分析。
- 合并间距阈值与判定参数扫描结果。
- 对金属环境多径与带体微动干扰的初步分析。

这些材料可用于学习小目标事件检测的数据特征，也可以作为后续产量统计、缺料告警与输送线节拍分析实验的基础。
