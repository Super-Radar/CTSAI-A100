# 非相干积累后 CA-CFAR 虚警率校准研究（a100-cfar-calibration）

单通道高斯噪声下推导的 CA-CFAR 阈值因子（`P_fa = (1+α/N)^(-N)` 的反解），直接用于
"多通道功率平均 + dB(power)"的非相干积累谱时，实际虚警率会大幅偏离名义值。本项目用
蒙特卡洛方法，把这一偏离在 CTSAI-A100 官方处理链（Hann 双窗 + 2D-FFT + 4 通道功率平均）
上量化出来，并给出可直接查表使用的经验阈值因子校正。

**诚实红线**：本项目的全部结论限于"合成高斯噪声流过官方处理链"的受控实验。仓内实测
ADC 数据仅用于谱形对照；实测数据无标签，本文不报告任何真实检测率或真实虚警率。

## 项目目标

1. **实现自证**：单通道白噪声 → 官方链路 → CA-CFAR，名义 P_fa ∈ {1e-2, 1e-3, 1e-4}，
   经验 P_fa 与名义值的偏差落入二项置信区间（用无窗对照配置验证实现正确性）；
2. **通道数效应**：K = 1..4 独立通道功率平均后沿用同一单视线阈值因子，量化虚警
   膨胀/紧缩倍数；
3. **相关性效应**：通道间相关系数 ρ ∈ {0, 0.3, 0.7, 1.0}（共享随机分量合成法）的
   同类量化，ρ=1 退化为单通道作交叉验证；
4. **dB 域误区**：在 dB(power) 图上按"均值 + k×σ"设门限（社区常见误用）与线性域
   正确 CA 门限的 P_fa 对比；
5. **校正交付**：K/ρ 网格上的经验阈值因子校正表（`results/exp5_alpha_calibration.csv`）
   与使用建议。

## 方法

### 官方处理链复现（`src/cfar_calib/pipeline.py`）

按只读参考 `ADC数据采集/matlab_signal_processing_platform_231023_for_txt_A100/`
逐文件复现：uint32 字 → 高/低 16 位两个连续实样本（`init_function/adc_mem_2_real_fixed.m`）
→ 每通道每 chirp 截齐/补零（`init_function/load_adc_data.m`，真实数据）→ Hann 距离窗
（实际采样点数）+ Range FFT（`rng_nfft`，取前一半）→ Hann 速度窗（chirp 数）+ Doppler
FFT（`vel_nfft`）（`FFT/do_fft_2d.m`）→ K 通道 `|velFFT|²` 平均 → `10·log10`（主脚本与
`FFT/calculate_global_noise.m` 的 `db(...,'power')`）。MATLAB 的
`rng_fft_scalar/vel_fft_scalar` 归一化为纯尺度因子，对 P_fa 不变量，故不复现；Doppler
轴 fftshift 仅影响展示（社区 validator 亦如此），不影响统计。合成噪声直接以实高斯样本
进入同一条链。

### CA-CFAR 拓扑（`src/cfar_calib/cfar.py`）

与现有社区参考 `community/projects/a100-matlab-adc-pipeline-validation/validator/
run_reference_validation.py::cfar` **完全同拓扑**，并有逐单元一致性测试
（`tests/test_cfar_topology.py` 对照其循环实现）：

* 二维环形训练窗：距离维单侧训练 8 / 保护 2，速度维单侧训练 6 / 保护 2，
  训练单元数 N = 21×17 − 5×5 = **332**；
* 距离维（有界轴）常数（零）padding，速度维（周期轴）wrap padding；
* 判决 = `power > α·Z` **且** 8 邻域局部极大 **且** 剔除距离维边缘 `tr+gr=10` 行。

本文区分两个统计口径：**阈值规则**（仅 `power > α·Z`）与**完整检测器**（再叠加局部
极大与边缘剔除，即 validator 实际输出的告警）。名义公式只描述前者；局部极大在
P_fa ≤ 1e-3 时影响为二阶（iid 下约 `1−8·P_fa`），在 1e-2 时约 −4%。

### 阈值因子与 P_fa 换算（iid 单元模型）

* 单视线（指数单元，validator 所用）：
  `P_fa = (1+α/N)^(−N)`，`α = N·(P_fa^(−1/N) − 1)`；P_fa=1e-4、N=332 时
  **α = 9.339**。
* K 通道功率平均（K 视线）：单元功率 `Y ~ Gamma(K, rate K)`（均值 1、方差 1/K）。
  记训练窗求和 S，则 `Y/(Y+S) ~ Beta(K, N·K)`，得精确式
  `P_fa = 1 − I_{α/(α+N)}(K, N·K)`（I 为正则化不完全 Beta 函数）；K=1 时退化为
  单视线公式。该式给出"无窗、单元独立"下的理论参考曲线。

### 通道相关性合成

`x_i = √ρ·s + √(1−ρ)·e_i`（s、e_i 为独立实高斯场）。ρ 为通道间**幅度**相关系数，
功率域相关为 ρ²；ρ=1 时各通道相同，K 通道平均严格退化为单通道（交叉验证锚点）。

### 经验 P_fa 统计与置信区间

每个蒙特卡洛点记录全部内部判决单元（距离维边缘 10 行已剔除）的
`ratio = power/Z`，及其中局部极大单元的 ratio。由于 α 只与 ratio 比较，一次仿真即得
整条经验 P_fa(α) 曲线与任意目标 P_fa 的经验分位数（即校准 α，无需迭代重仿真）。
经验 P_fa = 超越单元数 / 内部单元总数；区间用 Clopper–Pearson 精确二项 95% 区间：
`[B⁻¹(0.025; k, n−k+1), B⁻¹(0.975; k+1, n−k)]`。注意窗重叠使相邻单元弱相关，二项
区间为近似（无窗对照配置落区内支持其适用性）。

### 规模选择

扫描用**降采样配置**：chirp 数 256→64（`vel_nfft=64`），距离维保持全尺寸
（1021 样点 / 1024 点 FFT / 512 距离bin）。理由：① 单元数主要在距离维（512×64=32768
单元/帧，200 帧 = 6,297,600 单元/点）；② Hann 窗的相邻 bin 相关结构只取决于窗形
（|c|=2/3）而非窗长，chirp 数缩减不改变统计机制；③ 全部主结论在**全尺寸配置**
（256 chirp）上以 80 帧 × 125,952 单元 = 10,076,160 单元复核（实验 6），校准 α 的
全尺寸/降采样比值为 0.99–1.004，设计点 1e-4 处两者均落入目标区间内。

## 运行方法

```bash
cd community/projects/a100-cfar-calibration
PYTHONPATH=src python -m cfar_calib.cli            # 全量复现（默认 200 trials/点）
PYTHONPATH=src python -m cfar_calib.cli --trials 500
PYTHONPATH=src python -m cfar_calib.cli --quick    # 冒烟（24 trials，跳过真实数据）
```

日志见 `results/run_full.log` 与 `results/summary.json`）。

## 结果展示

### 实验 1：实现自证（`figures/fig1_selfcheck.png`，`results/exp1_selfcheck.csv`）

200 帧 × 31,488 内部单元 = 6,297,600 单元，K=1：

| 窗 | 统计口径 | P_fa=1e-2 | 1e-3 | 1e-4 |
|---|---|---|---|---|
| rect（对照） | 阈值规则 | 0.999 ✓ | 0.989 ✓ | 0.967 ✓ |
| rect（对照） | 完整检测器 | 0.959 | 0.985 ✓ | 0.967 ✓ |
| hann（官方） | 阈值规则 | 1.082 | 1.192 | **1.435** |
| hann（官方） | 完整检测器 | 0.669 | 0.907 | 1.221 |

（表中数值 = 经验/名义 P_fa；✓ = 名义值落入 95% Clopper–Pearson 区间。）

* **无窗（rect）对照全部落区内**（rect 完整检测器在 1e-2 处 0.959 的 −4% 偏差即上文
  局部极大项 `1−8·P_fa`，属公式口径而非实现误差）——实现自证通过。
* **官方 Hann 链在阈值规则下 P_fa 膨胀 1.08/1.19/1.44 倍**且随告警稀疏度增大：
  这是 Hann 窗使相邻 bin 功率相关（|c|²≈4/9，保护单元外的训练单元间仍有此相关），
  等效训练单元数减少所致。窗效应与 K/ρ 效应叠加，都被实验 5 的经验校准吸收。

### 实验 2：通道数效应（`figures/fig2_k_effect.png`，`results/exp2_k_effect.csv`）

左：官方链蒙特卡洛 P_fa(α) 曲线；右：iid 理论 `1−I_{α/(α+N)}(K,NK)`。在单视线名义
α（1e-2/1e-3/1e-4 → α=4.64/6.98/9.34）下，K 通道独立平均后的经验 P_fa
（阈值规则口径，因子 = 经验/名义）：

| K | 1e-2 | 1e-3 | 1e-4 |
|---|---|---|---|
| 1 | 1.082 | 1.192 | 1.435 |
| 2 | 0.115 | 0.0203 | 0（<5.9e-7，紧缩 ≥170×） |
| 3 | 0.0123 | 3.2e-4 | 0（<5.9e-7） |
| 4 | 0.00151 | 0（<5.9e-7） | 0（<5.9e-7） |

**结论**：4 通道独立平均后沿用单视线因子，1e-4 名义点的实际虚警率 < 5.9e-7
（6.3M 单元 0 检出），即虚警不是膨胀而是**坍缩两个数量级以上**——代价是灵敏度
损失（阈值比需要值高 2.3 倍 ≈ 3.6 dB，见实验 5）。

### 实验 3：相关性效应（`figures/fig3_rho_effect.png`，`results/exp3_rho_effect.csv`）

K=4、名义 1e-4（α=9.34）下随 ρ 变化（阈值规则因子）：ρ=0 与 0.3 均 0 检出（<5.9e-7）；
ρ=0.7 → 0.127；**ρ=1 → 1.339**，与 K=1 的 1.435 统计相容（两配置计数 843 vs 904，
z≈−1.5）；全曲线最大对数偏差 0.013（≈3%，47 个 α 点）——**ρ=1 退化为单通道的交叉
验证通过**。通道相关会迅速吃掉积累带来的紧缩：ρ=0.7 时 4 通道的实际虚警已回到名义的
1/8，ρ→1 时反超名义（叠加窗效应 1.3–1.4×）。

### 实验 4：dB 域误区（`figures/fig5_db_domain.png`，`results/exp4_*.csv`）

对 dB(power) 图在同一环形训练窗上取 `均值 + k×σ_dB` 门限（社区常见误用）。
纯噪声下达到目标 P_fa 所需的 k：

| K | P_fa=1e-2 | 1e-3 | 1e-4 |
|---|---|---|---|
| 1 | 1.68 | 2.02 | 2.28 |
| 4 | 2.01 | 2.53 | 2.94 |

两个问题：① **k 不随 K 迁移**——同一 k 在 K=1 与 K=4 之间 P_fa 相差可达一个量级
（dB 域 σ 随 Gamma(K) 形状收缩）；② dB 域分布左偏重尾，k 与高斯分位直觉严重不符
（高斯 1e-4 需 3.72σ，此处 2.3–2.9σ）。dB 域 k 不应作为 P_fa 的规范参数；正确做法是
线性域 CA 门限（本项目 `cfar.py`）+ dB 仅作显示。

### 实验 5：校正表（`figures/fig4_alpha_calibration.png`，`results/exp5_alpha_calibration.csv`）

K×ρ 网格、目标 P_fa=1e-4 的经验校准阈值因子（阈值规则口径；CSV 另含 1e-2/1e-3 与
完整检测器口径）：

| K＼ρ | 0 | 0.3 | 0.7 | 1.0 |
|---|---|---|---|---|
| 1 | 9.72 | —（同 ρ=0） | — | — |
| 2 | 6.08 | 6.67 | 8.29 | 9.71 |
| 3 | 4.71 | 5.65 | 7.98 | 9.57 |
| 4 | **4.05** | 5.10 | 7.61 | 9.66 |

参考：单视线理论 α=9.339；iid K 视线理论 α=5.93/4.67/4.00（K=2/3/4）。经验值与
K 视线理论在 ρ=0 处偏差仅 +2.6%/+0.8%/+1.2%（Hann 窗相关效应），ρ→1 平滑回到
K=1 值。"直接沿用单视线因子"相对校准值的阈值过设计：K=4/ρ=0 为 9.339/4.047 =
**2.31 倍 ≈ 3.63 dB 灵敏度损失**；K=2 为 −1.86 dB、K=3 为 −2.97 dB、K=4/ρ=0.3 为
−2.63 dB、K=4/ρ=0.7 为 −0.89 dB。

### 实验 6：全尺寸复核（`results/exp6_fullsize_check.csv`）

全尺寸配置（256 chirp/1021 样点/1024/256，Hann）80 帧 × 125,952 内部单元 =
10,076,160 单元：把降采样配置校准的 α 直接用于全尺寸，K=1 与 K=4 在设计点 1e-4 的
经验 P_fa = 9.49e-5 与 9.72e-5，均落入目标 95% 区间内；全尺寸/降采样校准 α 比值
0.99–1.004。1e-2/1e-3 点的迁移偏差 ≤4%（源于校准自身的蒙特卡洛不确定度，两个配置
的 95% 区间互不包含但中心一致）。**主结论在全尺寸配置成立。**

### 实验 7：真实谱对照（可选，`figures/fig6_real_spectrum.png`，`results/exp7_real_data_inventory.csv`）

远波 f0 四通道真实采集过同一链路：真实谱噪声底区域与合成 K=4 白噪声的 dB 分布
（各自减去官方 `calculate_global_noise` 区域均值后）形状吻合，真实谱右尾更重
（杂波/目标内容，合成噪声不覆盖）。同一帧上，单视线名义 α=9.34 检出 3 个单元，
K=4 校准 α=4.05 检出 287 个单元——直观展示"阈值过设计 3.6 dB"在真实谱上的表现。
**再次声明：仅为无标签数据上的检测计数，非检测率/虚警率结论。**

## 结论

1. **直接沿用单视线 α=9.34（P_fa=1e-4, N=332）于 4 通道功率平均谱，实际虚警率坍缩
   ≥170×（<5.9e-7/6.3M 单元），等效灵敏度损失 2.31 倍（3.63 dB）**；通道相关会削弱
   该坍缩（ρ=0.7 时回到名义的 1/8，ρ=1 时反超名义约 1.3×）。
2. **经验校正表**（上表 / `results/exp5_alpha_calibration.csv`，两种统计口径、三个
   P_fa 目标）：ρ≈0 时可直接用 K 视线精确式 `1 − I_{α/(α+N)}(K, N·K) = P_fa` 反解
   （`cfar.alpha_k_look`，与经验值偏差 ≤2.6%），或用本表经验值（同时吸收 Hann 窗
   相关效应，K=1 时窗效应约 +4%）。
3. **报告 CFAR 结果时应声明**：通道数 K、积累方式（功率平均/求和）、通道相关性假设、
   阈值因子来源（单视线公式 / K 视线公式 / 本表经验校准）。通道相关性未知时保守取
   ρ=1（单视线 α），虚警不超名义 × 窗效应（≈1.4×）。
4. dB 域"均值+k×σ"门限的 k 不随 K 迁移且偏离高斯直觉，不应作为 P_fa 规范参数。
5. 官方 MATLAB 平台主脚本本身不含 CFAR（仅全局噪声估计 + 峰值搜索）；本文校准的
   是社区 validator 拓扑的 CA-CFAR 在官方谱上的行为。

## 局限

* **合成噪声 ≠ 真实杂波**：真实环境杂波/干扰非高斯、非平稳，且通道相关性未知；
  本表只校准"高斯噪声过官方链"的统计行为。真实数据仅做谱形对照。
* **降采样外推近似**：扫描用 64 chirp 配置换取蒙特卡洛吞吐；已验证窗相关结构不依赖
  窗长、并在全尺寸配置复核（α 比值 0.99–1.004），但严格而言 64-chirp 的速度维
  统计（如 fftshift 后 DC 单元占比）与 256-chirp 略有差异。
* 经验 P_fa 的二项置信区间在窗重叠导致的空间弱相关下是近似；校准 α 的不确定度约为
  其对应 P_fa 区间宽度（1e-4 点约 ±8% P_fa，折合 α 约 ±4%）。
* `local-max` 判决使"完整检测器"口径在较高 P_fa（1e-2）处系统性低于阈值规则口径约
  4–30%；需要严格 P_fa 语义时用阈值规则口径并注明。
* 官方 hxx 的 DDMA/MIMO 编码未解码（社区 validator 亦如此）：4 文件按 4 个接收通道
  功率平均处理（与官方 `nvirtual_chirp=1` 时的 `RVimage` 语义一致）；若固件实际启用
  多发，通道模型需相应调整。
