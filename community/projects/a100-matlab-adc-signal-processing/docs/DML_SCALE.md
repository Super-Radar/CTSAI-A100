# DML 的幅度缩放不变性

输入为已标定、单位范数字典上的同一个方向时，整体复幅度不应改变角度。
原函数对绝对残差使用 `eps` 下限：4 阵元、30° 的非零快拍在幅度
`1e-8` 和 `1e-10` 下得到常数谱并返回网格首项 −60°。
这是数值缩放问题，并不代表硬件弱目标检测能力。

现在先按最大实/虚分量缩放，再单位范数化，避免直接平方导致下溢或上溢。
返回谱为**逆相对残差**，不再包含输入的绝对功率因子；现有绘图会归一化每条谱。
零快拍直接返回 NaN 角度和零谱；非有限或维度不符的输入明确报错。
字典仍应由 `steering_dictionary` 生成，不改变阵列几何、DDMA 或采集同步假设。

在本项目目录运行：

```matlab
addpath('tests'); run_dml_scale_tests;
```

回归覆盖两种阵列、−30/0/30°、有/无固定扰动、三种整体相位和
`1e-200` 至 `1e200` 七个幅度，共 252 次比较；另覆盖零输入和四类坏输入。
使用 GNU Octave 8.4.0 原生函数路径，无 table 适配器；MATLAB GUI 和硬件未验证。
同次运行的现有 `run_configuration_tests` 配置/MIMO 测试也通过。

本次 0.25° 网格下的原公式/修复后对照（已知方向 30°）：

| 全局幅度 | 原公式角度 | 修复后角度 |
|---|---:|---:|
| 1 | 30° | 30° |
| 1e-6 | 29.75° | 30° |
| 1e-8 | −60° | 30° |
| 1e-10 | −60° | 30° |

这证明的是保持信噪比的全局缩放不变性，不是降低噪声底或提升硬件灵敏度。
原生执行输出见 [DML_SCALE_TEST_OUTPUT.txt](DML_SCALE_TEST_OUTPUT.txt)。

与 [issue #100](https://github.com/Super-Radar/CTSAI-A100/issues/100) 的关系：
其公开修复通过拒绝常数谱处理不可观测输入，但 DML 仍保留绝对 `eps`。
本修复保留低幅度、实际上有方向信息的谱。测试同时验证其公开常数谱拒绝条件
对修复后的有信息输入成立；没有声称已运行该贡献者整个组合分支。
