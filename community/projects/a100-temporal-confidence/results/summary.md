# a100-temporal-confidence 关键结论

本文件由 `cli.py` 以固定种子 20261003 自动生成；所有数字可用同一命令复现。

## 有效样本量 N_eff

- 目标数序列（每帧目标数 n_t）：N_eff/N = 0.146 ~ 0.168（IPS 截断，max_lag = min(100, 5%·N)）。
- 网格占用序列（Δr=5 m × Δθ=10° 代表单元指示 o_t）：N_eff/N = 1.000 ~ 1.000。两族统计量的时间结构完全不同：目标数强正相关（帧间场景连续），而中占用率单元的检测闪烁近似 iid。
- 会话 B 的占用单元 B_cell1、B_cell2 呈周期-2 交替（ρ₁≈-0.95）：强负相关使 IPS 取 K=0、N_eff≈N，这是保守方向（交替序列均值的真实精度更高）。
- 结论：按 iid 假设直接用 N 计算目标数均值的标准误会高估信息量约 6~7 倍。

## 独立 bootstrap 对 CI 宽度的低估

- 目标数序列：iid bootstrap 的 95% CI 宽度只有 b*=N^(1/3) 块 bootstrap 的 1/1.7~1/1.6（低估 1.6×~1.7×）；若以块长扫描平台区（b≈60~70）的宽度为准，低估扩大到 2.7×~2.8×。
- 占用单元序列：比值 width_mbb(b*)/width_iid = 0.40~1.42，近 iid 单元≈1，负相关交替单元<1（iid 区间此时偏保守，方向相反）。

## 建议块长

- 参照值 b* = round(N^(1/3))：A_count=14, A_cell1=14, A_cell2=14, B_count=13, B_cell1=13, B_cell2=13。
- 目标数序列的 CI 宽度在 b=2..100 内持续上升，b* 处仅为平台区宽度的 59%~62%（偏小）；进入 ±5% 平台的最小块长 b_stab = 60~70。实用建议：强相关统计量取 b∈[30, 70]（约 2~5×b*），近 iid / 交替型单元取 b* 即可（近 iid 单元的 b_stab 低至 7）；块长接近 N/25 后估计方差明显增大。

## 合成 Monte Carlo 验证（AR(1)，N=800，M=400，B=400）

- iid 数据（φ=0）：各方法覆盖率 94.5%~95.8%，均接近 95% 名义水平。
- φ=0.9 时独立 bootstrap 覆盖率跌至 36.0%，块 bootstrap 最好达 84.5%（3b* 优于 b*，SBB 优于 MBB），验证了块结构对正相关序列的必要性。
- 截断法 N_eff 估计与解析式 N(1−φ)/(1+φ) 的最大相对偏差 13.2%（φ 越大截断偏差越大）。

## 非平稳与分段

- 已知均值阶跃（第 300、600 帧，段内 φ=0.3）的合成序列：CUSUM 检出 [295, 401, 600]——两个真实断点在 ±6 帧内命中，另有一个段内多余分裂（正相关会推高 CUSUM 统计量，分段结果需要人工核对）；分段 [0:295) n=295（ok），[295:401) n=106（ok），[401:600) n=199（ok），[600:800) n=200（ok）。
- 少于 30 帧的段输出 insufficient_samples（样本不足），不给 CI。
- 真实记录各序列断点数（n_change_points）：A_count=4; A_cell1=0; A_cell2=5; B_count=5; B_cell1=0; B_cell2=0；存在断点的记录不应套用单一全局 N_eff（见 README 局限一节）。
