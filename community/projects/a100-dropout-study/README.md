# a100-dropout-study：ADC 数据缺损对距离-多普勒谱影响的受控研究

针对 **CTSAI-A100** 雷达原始 ADC 数据，本项目在**离线、受控、固定种子**的条件下，
系统量化四类人工缺损对官方 MATLAB 信号处理链路输出的距离-多普勒（Range-Doppler）谱的
影响，回答一个实用问题：

> **ADC 数据"缺多少字以内，图还能看；超过多少，结论不可信？"**

并给出两种应对策略（官方式保位补零 vs 截断到完整 chirp 边界）的定量对比，以及一组
"峰位漂移 < 1 bin 且峰功率误差 < 1 dB"的可操作自检阈值。

---

## 1. 项目目标

- 在 NumPy 中逐行复现官方 MATLAB 平台（`ADC数据采集/matlab_signal_processing_platform_231023_for_txt_A100/`）的 ADC → 距离-多普勒功率图链路，作为谱级评测的"受试对象"。
- 定义四类受控缺损模型（随机丢字 / 连续零段 / 整 chirp 置零 / 尾部截断）与两种应对策略，在合成真值帧与仓内真实示例数据上注入缺损，测量五个谱级指标的退化曲线（每点 ≥ 10–20 次随机重复，取中位数与四分位距）。
- 从曲线提取各模型"最大可容忍缺损强度"阈值表，作为社区数据自检参考。
- 说明缺损谱影响与格式级审计（在审社区项目 `a100-adc-audit`）的互补关系：哪些缺损会被长度审计抓住、哪些静默通过。

**诚实红线（先说清楚）**：人工注入的缺损模型**不代表真实采集链路的故障分布**（真实 USB/文件链路的丢数模式未知）。本项目全部结论限于"**受控缺损模型 + 官方链路复现**"条件下的谱退化规律，是灵敏度研究，不是故障统计。

### 2.2 合成真值帧

按 `init0` 参数合成含**已知距离/速度单目标**的 ADC 字流（实余弦拍频信号 + int16 量化 +
2 LSB 高斯底噪）：R = 5.0 m（理论距离 bin ≈ 9.53）、多普勒 bin 恰为整数 12
（v = 12 × 0.1599 ≈ 1.919 m/s）、幅度 12000 LSB、固定种子。理论峰位由
`pipeline.RadarConfig.range_bin_of / doppler_bin_of` 给出，pytest 有对拍测试。

### 2.3 离线声明

本项目为纯离线分析（无硬件、无实测、无新采集），所有缺损均为人工注入。

## 3. 方法

### 3.1 官方链路复现（`src/dropout_study/pipeline.py`）

| 官方 MATLAB | 本项目函数 | 说明 |
|---|---|---|
| `init_function/adc_mem_2_real_fixed.m` | `unpack_words` | uint32 字 → 高 16 / 低 16 位有符号 int16 交错样本（高半字在前） |
| `init_function/load_adc_data.m` | `load_adc_words` | 超长截断 / 过短补零到 `rng_nfft/2 × nchirp` 字；平铺字流 `w` → chirp `w // words_per_chirp`（列优先 reshape + 转置）；**每个长度决策写入 `LoadReport` 落盘** |
| `FFT/do_fft_2d.m` | `rv_power_map` | 距离维 `hann(adc_sample_num)`（MATLAB 对称窗）→ Range FFT（`rng_nfft`，取前半）→ 速度维 `hann(nchirp_used)` → Doppler FFT（`vel_nfft`） |
| `ct_signal_processing_main_simple_CTASIA100.m` | `rv_map_average` | RVimage = 4 通道功率平均，输出 `[rng_nfft/2, vel_nfft]` |

该链路与社区项目 `a100-matlab-adc-pipeline-validation` 在原生 MATLAB 中验证过的口径一致，本项目不重复跑 MATLAB。

### 3.2 受控缺损模型（`src/dropout_study/corruption.py`）

缺损作用在字流（uint32 词）上，返回"缺损后字流 + 缺损位置掩码"。位置掩码视作
**已知信息**（相当于带序号的传输层能定位空洞）；severity = 0 时为严格恒等变换。

| 模型 | severity 含义 | 范围 | 物理类比 |
|---|---|---|---|
| ① `random_drop` 随机丢字 | 丢字比例（均匀随机位置） | 0 – 20% | 传输层随机丢包（按位补零） |
| ② `zero_segment` 连续零段 | 零段长度（字），位置 头/中/尾 | 1 – 64 | 存储块损坏 / 粘连读零 |
| ③ `chirp_zero` 整 chirp 置零 | 置零 chirp 数（随机选取） | 1 – 32 | 整包丢失（包=chirp） |
| ④ `tail_trunc` 尾部截断 | 截断比例（尾部缺失） | 0.5 – 10% | 采集提前结束 / 写文件中断 |

**两种应对策略**（同一缺损流上对比）：

- **a) 保位补零（`zerofill`，官方式）**：保留全部 chirp，缺失字就地置零。对模型④ 恰好等价于官方 `load_adc_data.m` 对短文件补零的行为。
- **b) 拒绝不完整数据（`reject`，截断到完整 chirp 边界）**：丢弃含任何缺失字的 chirp，仅用幸存 chirp（按原顺序）。对模型④ 等价于只保留 `floor(剩余字数/words_per_chirp)` 个完整 chirp。多通道时取各通道幸存 chirp 的交集。注意：内部 chirp 缺口后剩余 chirp 仍按均匀栅格做 Doppler FFT，对动目标会引入相位不连续——这是被如实测量的效应，不是实现缺陷。

### 3.3 谱级指标（`src/dropout_study/metrics.py`）

对参考（完好）与缺损两幅功率图 `P_ref[r,d]`、`P_tst[r,d]`（功率，非 dB）：

| 指标 | 定义 |
|---|---|
| 峰位漂移（bin） | 抛物线亚 bin 插值后的最强峰位置差；`drift_max = max(|Δ距离bin|, \|Δ速度bin\|)` |
| 峰功率相对误差 | `10·log10(max(P_tst)/max(P_ref))`（dB） |
| 总能量误差 | `10·log10(ΣP_tst/ΣP_ref)`（dB） |
| 谱相关系数 | 两幅 dB 图（`10·log10(P+1e-30)`）的 Pearson 相关系数 |
| 速度维杂散峰增量 | 在各自最强峰距离 bin 的多普勒切片上，统计高于切片峰值 −20 dB 的内部局部极大值（排除主瓣 ±3 bin），报告相对完好基线的计数增量 |

### 6.3 关键数值（真实远波 4 通道，中位数）

- 随机丢字 0.5% / 1% / 20%（保位补零）：峰功率误差 −0.04 / −0.09 / −1.93 dB，峰位漂移 < 0.002 bin。
- 整 chirp 置零 8 / 32 chirp（保位补零）：−0.28 / −1.09 dB，谱相关 0.67 / 0.50。
- 尾部截断 5%：保位补零 −0.01 dB、漂移 0.00 bin；拒绝不完整 −0.45 dB、漂移 0.00 bin（243/256 chirp）。
- 两种策略同台对比最鲜明的场景是尾部截断：**补零几乎无损（等价于零填充），拒绝策略因相干积累 chirp 数减少而额外损失约一半 dB 值**（10% 截断：−0.06 vs −0.93 dB）。

## 7. 结论（自检阈值与适用条件）

**适用条件**：结论限于受控缺损模型 + 官方 MATLAB 链路复现（init0/init1 参数、官方示例
数据场景）、指标取 ≥10–20 次随机重复的中位数；换场景（弱目标、密集多目标、不同 SNR）
需重新标定。

1. **散布随机丢字 + 保位补零**：谱级非常稳健，~10% 丢字内峰位/峰功率均可信。长度审计
   静默通过的散布丢字，在谱上大多也确实"看不出来"——但这不等于无害，弱目标场景需另行评估。
2. **拒绝不完整 chirp 策略只适合"边界已知"的缺损**：尾部截断和整 chirp 缺损可用；对散布
   丢字是灾难（4 通道数据 0.5% 丢字即无可幸存 chirp，单通道数据也迅速退化为个位数 chirp）。
   若必须在中部缺口后继续处理，应考虑按真实 chirp 时刻做非均匀 DFT，而非均匀 FFT。
3. **整 chirp 置零是"每受影响字杀伤力"最高的模型**（每字带走整个 chirp 的 1020 个样本）：
   自检阈值 ~12% 置零 chirp 数（init0 约 29 chirp 插值边界；init1 更敏感，约 9%）。
   它同时是内容级启发式（"整 chirp 全零"）最容易抓到的缺损。
4. **尾部截断最温和**：官方"短文件补零"行为在谱级几乎无损（10% 丢尾 −0.06 dB），且任何
   ≥1 字的尾部丢失都会改变文件长度、被长度审计捕获——审计与谱影响在此一致。
5. **连续零段 ≤64 字（0.05% 字流）完全不可测**（|ΔP| < 2×10⁻⁶ dB，头/中/尾无差别）；
   若真实故障出现更长零段，请参考"整 chirp 置零"档位（零段拉长到 chirp 量级即等价于
   模型③）。

## 8. 局限

- **人工缺损 ≠ 真实故障分布**（最重要）：四类模型及其参数范围是人为选择的，真实
  USB/内存/文件链路故障的模式与比例未知；本研究的曲线是灵敏度，不是概率。
- 缺损位置掩码按"已知"处理（oracle）；真实系统若无传输层序号，只能靠启发式部分恢复。
  字删除导致流滑移（后续数据整体错位）的场景**未**建模——它严格劣于两种策略，属另一类问题。
- 谱相关系数在合成无噪帧上退化为 ≈0（其 dB 底噪由不相关数值噪声主导），仅对真实场景
  图有区分度；阅读时请以真实数据列为准。
- 官方链路中的相位补偿、CFAR、DOA 等后续环节未纳入评测（本项目止步于 RVimage）；
  MATLAB 与 NumPy 的浮点差异在 dB 指标上 << 0.01 dB，但未做逐位对拍。
- 每档中位数掩盖尾部行为：reject 策略在部分档位的 IQR 极宽（个别重复只剩 1–2 个幸存
  chirp），使用阈值时应同时看 `n_unusable` 与 q25/q75 列。

## 9. 与现有社区项目的关系

- **`community/projects/a100-adc-audit`（在审 PR）**：格式级审计（长度/哈希/饱和） vs 本
  项目的谱级影响，互补不重复。衔接结论（实验 5，详见 `results/summary.md`）：尾部截断
  ≥1 字即改变文件长度，**会被其长度审计捕获**；随机丢字（按位补零）、连续零段、整 chirp
  置零**长度不变、静默通过**长度审计——其中整 chirp 置零可被"整 chirp 全零"启发式稳定
  捕获、较长连续零段可被"全零游程"规则捕获，散布单字丢零仅凭数据侧无法发现。本项目为
  这些"静默通过"的缺损提供了谱级风险评估。引用其规则思路，未重复实现。
- **`community/projects/a100-matlab-adc-pipeline-validation`（已合并）**：其原生 MATLAB
  验证了官方 ADC 链路的正确性并做了长度校验提示（"能画图但数据可能已缺损"）；本项目
  沿用同口径链路，把"缺损后图还能不能信"定量化，是其长度校验思想的下游延伸。
