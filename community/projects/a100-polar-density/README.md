# a100-polar-density：极坐标点云热图的面积归一化与守恒重分箱

对 RadarTools 上位机导出的 RawTarget 多帧目标日志做**离线**空间统计：
把等角度极坐标网格上的"每扇区检测计数"归一化为**面积归一密度**
（检测数 /(扇区面积 × 帧数)，单位 detections·m⁻²·frame⁻¹），
并给出**守恒重分箱**（等面积网格、笛卡尔网格）与合成基准，
量化"计数热图"中 ∝ r² 的格元面积混杂对热点排名的影响。

## 目标

1. **计数图 vs 密度图**：同一份数据在等角度极坐标网格（默认 Δr = 1 m、Δθ = 1°）上，
   逐扇区计数与面积归一密度并排对比，给出 top-20 热点在两种表示下的名次位移。
2. **守恒重分箱**：极坐标密度场到等面积网格（sqrt 间距径向边界，环带面积相等 + 均匀角度划分）
   与笛卡尔网格的转移，核验 Σ密度×面积 = Σ计数（相对容差 1e-9）。
3. **等面积 vs 等角度分箱的密度可比性**：密度是分箱不变的物理量，计数不是。
4. **合成基准**：面积均匀环带撒点 → 计数随 r 增长而密度平坦；已知热点 + 均匀背景的恢复。

## 数据来源

全部为本仓自带的官方示例数据（只读，不修改任何官方文件）：

- 主输入：`Python雷达可视化工具示例/负30度_Tatget_2026_03_10_15_34_39_CTLRR-300-V2_1_RawTarget.csv`
  （2463 帧、35803 条目标行；文件名标注 CTLRR-300-V2_1）。
- 复核语料：`RadarTools/RadarTools_Release/data/` 下 21 个 `*_RawTarget.csv`
  （共 6792 帧、304870 条目标行）。

22 个文件的 SHA256 清单见 [`results/data_sha256.txt`](results/data_sha256.txt)。
CSV 为逐帧块结构（`START,FrameNb:N` → 时间戳行 → `heightOffset:` 元数据行 → 目标行 → `END,Total:N`），
表头列数存在 57/58/59/62 多种变体（主输入 57 列），前 5 列恒为
`ObjId,range,speed,angle,snr`，解析器按位置索引、逐帧解码，不假设全文件单表头。

> 说明：这些是 RadarTools 上位机的示例目标日志（CTLRR-300-V2_1 标注，仓内官方附带资产，
> 官方 Python 可视化文档亦用同款 CSV 作示例），**并非 A100 硬件实测数据**。

在本仓任意 checkout 内（工作树根目录记为 `$REPO`）：

```bash

# 完整分析：解析主输入 + 21 文件语料复核，生成 figures/ 与 results/

# 分箱宽度可参数化：--dr 2.0 --dtheta 2.0
```

退出码 0 表示全部守恒核验通过。

关键结论（详见 `results/summary.md`）：

- 主输入网格 114×105 扇区中最小/最大扇区面积比 **1:46**（0.0436 → 2.02 m²）；
  计数与密度的秩相关仅 ρ = 0.74，**3 个计数 top-20 热点在密度图中跌出 top-20**，
  名次位移范围 [−10, +12]、中位 −3。
- 分箱不变性精确核验：等面积网格环带均值 vs 无分箱区间直接计算，最大相对差 ~1e-16。
- 守恒：极坐标→等面积重分箱、笛卡尔重分箱、极坐标/笛卡尔总权重（35803 = 35803 = 35803）
  全部通过（相对误差 ≤ 4e-16）。
- 合成基准：均匀环带计数最外/最内环比 ≈ 11×，密度平坦（最大环带偏差 5.74%）；
  已知热点在密度图中于 1 个扇区精度内恢复。

## 局限

- **检测输出密度 ≠ 真实目标密度**：分析对象是上位机检出的目标点，检测层的漏检/虚警、
  聚类与跟踪行为全部混入"密度"。
- **面积归一不能补偿检出率的空间不均匀**：距离相关检出率（SNR 随 r 衰减）、遮挡、
  多径以及未知/未标定的视场覆盖都会让"平坦密度"不再等价于"均匀目标分布"。
- **离线分析、未硬件实测**：未连接 A100 硬件复测，输入为仓内示例日志；
  帧数曝光归一假设各帧采样等权，未建模帧间时间间隔差异（如丢帧）。
