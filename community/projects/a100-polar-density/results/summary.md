# a100-polar-density 结果摘要

固定随机种子 `20261003`；全部产物可由 `cli.py` 复现。

## 输入概览

- 主输入：`Python雷达可视化工具示例/负30度_Tatget_2026_03_10_15_34_39_CTLRR-300-V2_1_RawTarget.csv`
  （表头 57 列变体，2463 帧，35803 条目标行；
  range 2.30–115.08 m，angle -38.70–65.35°）。
- 复核语料：`RadarTools/RadarTools_Release/data/` 下 21 个 `*_RawTarget.csv`，
  共 6792 帧、304870 条目标行（SHA256 见 `data_sha256.txt`，共 22 个文件）。
- 分箱网格：Δr = 1 m、Δθ = 1°（半开区间 [a, b) 约定），覆盖数据范围
  r ∈ [2, 116] m、θ ∈ [-39, 66]°，
  共 114 × 105 = 11970 个扇区。

## 实验①：计数图 vs 密度图与热点名次位移

- 活跃（非零）扇区 251 个；计数与密度的 Spearman 秩相关
  ρ = 0.7438（≠1 的部分完全来自扇区面积差异）。
- **面积偏置量级**：全网格最小/最大扇区面积比 1:46
  （最内环扇区 0.0436 m² → 最外环扇区 2.02 m²）；
  同样目标密度下远距扇区计数天然按面积放大。计数与密度的秩相关仅
  ρ = 0.7438（扇区级计数-面积 Spearman ρ = 0.2058：
  大扇区在同等密度下天然多收检测；纯面积伪影在合成基准中单独量化）。
- **热点名次位移（top-20 计数热点）**：中位位移 -3 名，
  范围 [-10, +12]；5 个被面积归一提升、
  14 个下降、1 个不变；
  **3 个计数 top-20 热点在密度图中跌出 top-20**。
  明细见 `hotspot_rank_shift.csv`（shift = 计数名次 − 密度名次，正=归一后更热）。

## 实验②：等面积分箱的密度可比性

- 等面积网格（sqrt 间距径向边界，环带面积相等 + 均匀角度划分）：单扇区面积
  1.03 m²，全网格面积相对离散度 4.6e-14（浮点误差量级）。
- **分箱不变性（精确核验）**：等面积网格的环带平均密度与不经分箱、直接按径向区间计算的均值
  最大相对差 6.0e-16——密度是分箱不变的物理量，原始计数不是。
- 两种分箱的环带密度剖面结构一致（Spearman ρ = 0.7706）。
  作为对照，环带**计数**不具有这种不变性：等角度网格的环带计数与环带面积的
  Spearman ρ = -0.4169（符号与方向取决于目标分布，量级 1:46
  的面积差异始终是计数表示中的混杂因子；合成基准单独给出纯面积伪影 ~11×）。

## 实验③：笛卡尔重分箱对照（同权重总量）

- 同一批检测在极坐标网格与 1 m×1 m 笛卡尔网格上的总权重均为 35803
  （= 检测总数），密度面积分相等；差异只在空间表示：极坐标等角度扇区面积 ∝ r²，
  笛卡尔格元面积恒定，计数热点图因此呈现不同的偏置模式。

## 合成基准（seed = 20261003）

- 均匀环带（r ∈ [5, 80] m，面积均匀撒点 160000 点 / 200 帧）：
  最外/最内环带计数比 ≈ 11.0×（计数随 r 增长），
  面积归一后环带密度最大偏差 5.74%（平坦）。
  纯均匀背景的计数峰值出现在第 74/74 环
  （最外环附近，纯面积伪影），密度峰值则无此偏移。
- 已知热点（真值 r = 45 m, θ = +20°，共 24000 点）：
  密度图峰值扇区位于 r = 44.5 m, θ = +19.5°（1 个扇区内），
  该扇区密度名次第 1、原始计数名次第 1——面积归一恢复真实最热点。

## 结论

计数热图在等角度极坐标网格上带有 ∝ r² 的面积混杂（量级 1:46）：
相同目标密度下远距扇区计数天然更高，实测 top-20 计数热点中有 3 个
在密度图中跌出 top-20；密度 = 计数/(扇区面积×帧数) 修正后，热点排名、跨距离可比性与分箱不变性均恢复。
注意：这是**检测输出密度**，不是真实目标密度（见 README 局限）。
