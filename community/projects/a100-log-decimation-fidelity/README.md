# 点云日志时间抽稀的离线保真边界（a100-log-decimation-fidelity）

RadarTools 上位机在长会话中持续落盘目标点云帧（RawTarget CSV），日志体积随帧数线性增长。若归档/传输前对日志做"时间抽稀"（丢弃部分**完整目标帧**），离线能回答的问题是：给定压缩比，抽样日志相对完整日志的保真边界在哪里？本项目在**纯离线、无硬件实测**的前提下量化该边界。

## 项目完成了什么

- 严格解析 RawTarget 多帧方言（57/58/59/62 列表头变体、按位置取列、尾逗号、END,Total 校验、尾部固件签名行），输出帧序列（epoch ms 时间戳 + 每帧 (range, angle, snr)）；
- 三种抽样策略：
  - **等间隔 keep-every-k**（k=2..16），对每个 k **确定性枚举全部相位** φ∈{0..k−1}；
  - **时间分层抽样**：记录时长等分 B 段、每段随机抽帧（`numpy.random.default_rng`，固定种子，同种子同结果）；
  - **字节预算模式**：目标压缩比 C 反推 k=⌈C⌉；
- 保真指标（`src/decimation/fidelity.py`，语义由测试固定）：
  - **时间加权极坐标占据直方图**（Δr=0.5 m × Δθ=2° 网格，权重=帧曝光时长）的 L1（TV 约定，0.5·Σ|p−q|）与 L2 距离；
  - **短命网格单元保留率**：出现时长 < T=1 s 的单元抽样后是否仍被观测到；
  - **统计量保持**：每帧目标数均值/中位/P90 误差；
- **权重守恒语义**（测试固定）：帧 i 拥有相邻帧间隙中点之间的曝光区间，Σ=完整记录时长；抽样后，被抽掉帧的曝光并入**最近保留帧**（索引 Voronoi，平局归更早的保留帧），因此抽样后总时间权重恒等于完整记录时长；
- 合成基准：已知出现时刻与持续帧数的**脉冲串**短时响应——解析可算哪些相位必漏（跨 L 帧的响应必被 k 个相位中的 max(0, k−L) 个整段遗漏，L≥k 不可能整段漏），测试逐一枚举验证与解析一致；**不规则 Δt 序列**——时长相等的稀疏/稠密两半，时间加权使两单元占据各≈0.5，计数加权使稠密侧过权约 10×。

## 结果（详见 `results/summary.md`，由 cli 自动生成）

1. **误差-压缩比**：等间隔抽稀的 L1 呈强**奇偶锯齿**——偶数 k ≈ 0.10-0.12，奇数 k ≈ 0.014-0.040。根因是主输入内容本身按帧序奇偶交替（偶/奇帧直方图 TV=0.199，均值角度差约 4°，多个镜像单元近乎互换），偶数 k 锁定单一奇偶类而奇数 k 在两类间交替。**时间分层抽样**误差平滑增长 0.014（k=2）→ 0.042（k=16），同压缩比下比偶数 k 等间隔低 2.5-7 倍，10 次固定种子抽样 std ≤ 0.003。
2. **最坏相位表**（`worst_phase.csv`）：相位选择对 L1 影响不大（最坏/最好 ≤ 1.2×，被奇偶效应主导），但对短命保留影响大：k=2 最差相位丢 31% 短命单元（79/252），k=8 丢 69%（175/252），k=16 丢 78%（196/252）。
3. **短命响应保留边界**（`short_response_retention.csv`）：保留率由出现时长主导、与抽样器种类基本无关——出现 <0.2 s 的单元（n=147）在 k=2 保留 0.57-0.60、k=8 保留 0.14-0.20、k=16 保留 ~0.08；0.6-1.0 s 的单元在 k≤4 基本全保留、k=8 起明显下降。合成脉冲串给出解析边界：跨 L 帧的响应必被 max(0, k−L)/k 比例的相位整段遗漏，L ≥ k 时不可能被整段遗漏。
4. **字节预算**：按平均每帧字节估算（主输入 6023 B/帧），主输入 14.79 MB → k=8 约 1.85 MB、k=16 约 0.92 MB；第二输入 6.58 MB → k=8 约 0.82 MB。C → k = ⌈C⌉。

图（英文标签、带单位）：`fig1` 误差-压缩比两面板（上：L1；下：短命保留，即"双轴"以并列面板实现，避免双 y 轴刻度混淆）；`fig2` 每 k 的最坏/中位/最好相位（含最差相位标注 φ）；`fig3` 短命单元遗漏示例（同一单元：k=3 相位 2 整段漏 / 相位 0 保留）；`fig4` 字节预算视角（两输入的估算保留体积 vs C）；`fig5` 合成基准验证（脉冲串解析 vs 枚举；时间加权 vs 计数加权）。

## 局限

- **完整日志仍非真实世界真值**：所有"保真"都是相对完整日志而言；
- **保真仅对已记录响应**：完整日志中不存在的目标，任何抽样方案都不可能恢复；抽样也不代表降低实际发射帧率的效果（那是雷达侧帧率问题，不是日志侧抽样问题）；
- **离线分析、未硬件实测**：输入是 CTLRR-300-V2_1 上位机示例日志，非 A100 硬件数据；
- 字节预算按每帧平均字节估算，未逐帧精确计量；短命阈值 T=1 s、网格 Δr=0.5 m / Δθ=2° 为本项目约定（cli 参数可调），改参数会改变量级但方法不变。
