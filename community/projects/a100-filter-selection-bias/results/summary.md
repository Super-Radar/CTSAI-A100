# a100-filter-selection-bias 关键结论

- 生成：`cli.py`（固定种子 20261003）；数据：22 个 RawTarget 文件（CTLRR-300-V2_1），共 340,673 条目标行、9,255 帧；表头列数变体：57 列 x1 个文件、58 列 x1 个文件、59 列 x2 个文件、62 列 x18 个文件；18/22 个文件含非零 speed。

## 实验① 近零速度过滤的整体隐藏程度

- v_min=0.5 m/s 时总体删除 56.4%（保留 43.6%，148,388/340,673）；语料中 |speed|<0.5 的观测占比 56.6%（fig5 子采样口径）。
- 删除并非空间均匀：受创最重的距离带为 [100,150) m（保留 24.9%），受创最重的角度扇区为 |angle| [60,+inf) deg（保留 1.4%）。
- v_min 从 0 扫到 2 m/s，保留率从 100% 降至 42.9%（retention_sweep.csv 分层行量化各带损失）。

## 实验② 各筛选维度删除集合的交集

- 参考设置（R≤150 m、|angle|≤60 deg、|v|≥0.5、|v|≤30 m/s、snr≥10 dB）下逐维取删除集：
  - angle_max x speed_min：Jaccard=0.055（交集 10,514 / 并集 192,431）
  - range_max x speed_max：Jaccard=0.004（交集 105 / 并集 25,111）
  - angle_max x speed_max：Jaccard=0.003（交集 87 / 并集 33,843）
- 两两 Jaccard 全部 ≤ 0.055：五个维度的删除集合**基本互不相交**，多阈值叠加时的重复计数损失有限。
- 但包含率（交集 / 较小删除集）揭示了单向覆盖：98.6% 的 angle_max 删除集同时落在 speed_min 删除集内——即近零速度剔除几乎吸收了另一维的全部删除，叠加它对总删除量的边际贡献很小。

## 实验③ snr_min 与 range_max 的联合作用（远距离低 SNR 双重打击）

- (R_max=150 m, s_min=15 dB) 联合保留 99.0%，若两维删除独立应为 98.9%，交互量 +0.0014（负=删除共享，双重打击）。
- 本语料中该“双重打击”量级很小：range>150 m 的观测仅 0.6%，其中 snr<15 dB 的仅 0.1%——远距低 SNR 点几乎不存在，两维删除难有交集。
- 交互最强的组合是 v_min x s_min 的高 SNR 端：最负交互在 (v=0.7, s=30.0)，交互 -0.123；snr<30 dB 的观测中 35.7% 同时 |speed|<0.5 m/s（低 SNR 观测多为静态杂波，两个阈值在删同一批点，joint_grid.csv、fig3）。

## 实验④ 筛选前后分布偏移

- v_min=0.5：range 均值 32.6 -> 41.8 m（Δ+9.2 m，分布向大值偏移），angle 均值 -> -2.93 deg（近零删除集中于特定距离带/方位，见 fig5）。
- s_min=15：range 均值 32.6 -> 32.2 m（Δ-0.4 m，分布向小值收缩；分位数曲线见 fig4、distribution_shift.csv）。

## 局限

- 无真值标注：本报告只评价保留率与分布变化，不给出准确率/召回率，不评选“最佳检测阈值”。
- 数据为 RadarTools 示例目标日志（CTLRR-300-V2_1 标注，非 A100 硬件实测）；全部为离线分析。
- 结果可由 `python -m filter_bias.cli`（或 `python src/filter_bias/cli.py`）确定性重跑。
